# ClearDesk 0.5.0 · 首次公开测试版

免费、无广告、无遥测的 Windows 开源桌面整理器，采用 MIT 许可。

## 下载与运行

下载下方 `ClearDesk-0.5.0-windows.zip`，解压后运行 `ClearDesk.exe`，保留同目录的配置文件和 `ClearDesk.IconGuard.exe`。需要 Windows 10/11 与 .NET Framework 4.8，无需管理员权限。`ClearDesk-0.5.0-source.zip` 为源码包，`SHA256SUMS-0.5.0.txt` 提供校验值。

## 功能

- 自动分类、默认折叠、半透明灰色分区、重命名和背景浓度调整。
- 分区移动、缩放及位置和大小锁定；锁定状态跨启动保存。
- 系统图标、文件手动排序、跨分区拖放、拖出到桌面及向其他应用拖放。
- 搜索、托盘控制、配置导入导出。
- 移动前预览、撤销、全部恢复与中断恢复；正常退出默认恢复已整理文件，冲突时保留文件并提示。
- 原创图标；源码和图标均采用 MIT 许可。

自动分类只建立入口，确认「整理桌面（移动文件）」的预览才会搬动文件。异常退出后助手恢复原桌面图标显示，已搬动文件仍在收纳目录，可重新运行后恢复。请勿删除收纳目录或移动历史。

## 验证

98 项自动检查与隔离桌面的窗口交互检查通过。混合 DPI、Explorer 重启已通过作者本机手动验收；不同机器、虚拟桌面及更多动态壁纸类型仍需反馈。当前使用独立透明窗口，未嵌入 Explorer 桌面，发布包未附数字签名。
