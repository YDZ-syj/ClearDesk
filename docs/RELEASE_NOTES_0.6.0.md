# ClearDesk 0.6.0 · 后台操作与完整备份

新增后台整理和恢复、进度与取消、预览逐项勾选、文件改名跟踪，以及包含布局和移动日志的完整 ZIP 备份。已完成历史可归档，待恢复项目继续保留。

取消在当前文件处理完成后生效，已经移动的文件仍可恢复；恢复不会覆盖同名文件。文件在原文件夹内改名后，入口和顺序继续保留，整理日志同步更新。配置导入前需要先恢复已整理文件。

图标保护助手已整合到主 EXE，Windows 版可仅使用 `ClearDesk.exe`。开机自启、手动检查更新、可选自动提醒、分区锁定和透明背景继续保留，不修改 Wallpaper Engine 设置或桌面宿主。

从 0.5.x 升级时，先从托盘退出旧版，再解压新版运行。原配置目录和移动记录继续使用，不要删除收纳目录。软件位置变化后请重新开启开机自启。

下载 `ClearDesk-0.6.0-windows.zip`。源码包及 SHA-256 校验文件同时提供。需要 Windows 10/11 和 .NET Framework 4.8，免费开源、无广告、无遥测。

详见[使用指南](https://github.com/YDZ-syj/ClearDesk#readme)与[验证记录](https://github.com/YDZ-syj/ClearDesk/blob/main/docs/TESTING.md)。
