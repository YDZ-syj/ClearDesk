# ClearDesk 0.5.1 · 开机自启与更新提醒

新增「更多 → 开机自启」选项，默认关闭。勾选后随当前 Windows 用户登录启动，显示桌面分区，管理窗口收起到托盘；取消勾选可移除自启项，无需管理员权限。

自启选择保存在当前用户的 Windows 启动项中，导入分区配置不会改变它。移动软件文件夹后需在新位置重新开启一次；删除软件前请取消勾选。已经运行时，重复自启会静默退出。

新增「检查更新」与「自动提醒新版本」（默认关闭）。自动提醒每天最多查询一次 GitHub 公开版本，同一版本不重复提示；点击通知可打开下载页面，不自动下载和安装。不上传文件、配置、用户名或本机路径，断网不影响整理功能。

0.5.0 没有更新检查功能，旧版用户需先手动升级到本版，之后才能开启程序内的自动提醒。

下载 `ClearDesk-0.5.1-windows.zip`，解压后运行 `ClearDesk.exe`，保留同目录配置和图标保护助手。升级前从托盘退出旧版，个人配置和文件移动历史可继续使用。

需要 Windows 10/11 和 .NET Framework 4.8。免费、无广告、无遥测，源码及图标采用 MIT 许可。

详见[使用指南](https://github.com/YDZ-syj/ClearDesk#readme)与[测试记录](https://github.com/YDZ-syj/ClearDesk/blob/main/docs/TESTING.md)。
